# Ligase Healthcare — Official Website

Official website for **Ligase Healthcare** — an integrated healthcare services, medical coding, professional skill development, internships, and certification support partner.

Built from the complete website specification in `Ligase_Healthcare_Complete_Website_Script.pdf`.

- **Domain:** `https://ligasehealthcare.com`
- **Email:** `info@ligasehealthcare.com`
- **Tagline:** *Empowering Healthcare. Building Skills. Creating Opportunities.*

## Technology Stack

| Layer       | Technology                                    |
| ----------- | --------------------------------------------- |
| Framework   | Next.js 16 (App Router, React 19, Turbopack)  |
| Language    | TypeScript (strict mode)                      |
| Styling     | Tailwind CSS v4 & modern responsive CSS       |
| Graphics    | Interactive Canvas Network Animation          |
| Icons       | `lucide-react`                                |
| Fonts       | Plus Jakarta Sans (headings), Inter (body)    |
| Validation  | Zod + Server Actions                          |
| SEO         | Structured Schema (JSON-LD), OpenGraph & XML  |

## Website Architecture

- **Home:** Complete 16-section flow with dynamic interactive network animation
- **About Us:** Purpose, Mission, Vision, and Healthcare Ecosystem
- **Healthcare Solutions:** Medical Coding (Inpatient/Outpatient/HCC), Quality & Workforce
- **Training Programs:** Skill Development Programs (SDP), Short courses, 5-step journey
- **Internships:** Final-semester internships, eligibility, and structured 3-phase curriculum
- **Certifications:** AAPC / AHIMA pathways (CPC, CCS, CRC) & exam journey
- **Careers:** Opportunities for Coders, QA Auditors, and Trainers
- **Contact Us:** Interactive contact and consultation booking

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
